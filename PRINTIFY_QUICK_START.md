## 🎨 How to Use

### Step 1: Browse Products with Search

1. Go to: `https://affiliateflow-abzfy.web.app/dashboard/products/create-printify`
2. Use the search bar to find products:
   - Type "tee" → Find all t-shirts
   - Type "gildan" → See all Gildan brand items
   - Type "mug" → Find mug options
3. Filter by category: All, Apparel, Accessories, Home
4. Click any product to continue

### Step 2: Select Print Provider

- Choose between 2 providers (LA or NY location)
- See production times
- Click "Next" to continue

### Step 3: Upload Your Design

- Drag & drop an image file
- Or click "Choose File" to browse
- Supports PNG and JPG
- Max 50MB
- See instant preview

### Step 4: Configure Variants with Profit Calculator

**Individual Pricing:**
- Click any variant to select it (purple border)
- Enter retail price (e.g., $29.99)
- See instant calculations:
  - Wholesale: $12.99
  - **Profit: $17.00**
  - **Margin: 56.69%**

**Bulk Pricing (NEW!):**
- Select multiple variants
- Use "Bulk Price Update" card at top
- Enter one price (e.g., $29.99)
- Click "Apply to All"
- All selected variants updated instantly!

### Step 5: Product Details

- Enter product title
- Write description
- Add tags (comma-separated)
- Click "Create Product"
- Success! 🎉

## 📊 Profit Calculator Breakdown

### Understanding the Numbers

**Wholesale Cost**: What you pay Printify when someone orders
**Retail Price**: What customers pay you
**Profit**: Your earnings (Retail - Wholesale)
**Margin**: Profit as percentage of retail price

### Example Calculations

#### Example 1: Standard T-Shirt
```

Wholesale:     $12.99
```

## 🔧 Common Issues & Solutions

### Issue: "No products found"
**Solution**: Clear your search term or try a different keyword

### Issue: Can't see profit calculator
**Solution**: Make sure you've selected the variant first (click to select, purple border appears)

### Issue: Bulk price not applying
**Solution**: 
1. Ensure you have variants selected first
2. Enter a valid price (positive number)
3. Click "Apply to All" button

### Issue: Search not working
**Solution**: Check spelling, try broader terms (e.g., "shirt" instead of "t-shirt")

## 🎓 Best Practices

### Design Upload
- **Resolution**: 300 DPI minimum for best quality
- **Format**: PNG with transparent background (recommended)
- **Size**: Under 10MB for faster uploads
- **Dimensions**: Follow Printify's guidelines per product

### Product Titles
- Be descriptive: "Vintage Sunset Beach Graphic Tee"
- Include key features: Material, fit, style
- Use keywords: Help customers find products
- Keep under 60 characters

### Descriptions
- Highlight benefits, not just features
- Include sizing information
- Mention care instructions
- Add call-to-action

### Tags
- Use 5-10 relevant tags
- Mix broad and specific terms
- Include style keywords
- Add seasonal tags when relevant

### Pricing Strategy
- **Research competitors**: See market rates
- **Consider perceived value**: Quality + design
- **Test different tiers**: A/B test prices
- **Bundle discounts**: Offer multi-item deals

### Common Questions

**Q: Is this connected to real Printify API?**
A: Currently in demo mode with mock data. Real API can be enabled by changing one flag.

**Q: Will my products actually be created?**
A: Demo mode simulates creation. In live mode, products will be created in your Printify account.

**Q: Can I switch to live API?**
A: Yes! See `PRINTIFY_ENHANCEMENTS.md` Phase 2 for instructions.

**Q: How do I get a Printify API token?**
A: 
1. Sign up at printify.com
2. Go to Settings → API
3. Generate new API token
4. Add to environment variables

**Q: What happens when someone orders?**
A: 
1. Customer orders from your store
2. Order sent to Printify automatically
3. Printify prints and ships directly to customer
4. You pay wholesale cost, keep the profit
