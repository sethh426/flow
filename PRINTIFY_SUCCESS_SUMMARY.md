## Code Examples

### Browse Catalog
```typescript
import { getPrintifyCatalog } from '@/services/clientPrintifyService';

const catalog = await getPrintifyCatalog();
console.log(`Found ${catalog.all.length} products`);
// Apparel, Accessories, Home categories available
```

### Upload Design
```typescript
import { uploadDesignImage } from '@/services/clientPrintifyService';

const file = event.target.files[0];
const image = await uploadDesignImage(file);
console.log('Image ID:', image.id);
```

### Create Product
```typescript
import { createPrintifyProduct } from '@/services/clientPrintifyService';

const product = await createPrintifyProduct({
  title: "Awesome T-Shirt",
  description: "Cool design on soft cotton",
  blueprintId: 5,
  printProviderId: 99,
  designImageId: "abc123",
  variants: [
    { variantId: 17390, price: 24.99 }, // Black, XL
    { variantId: 17395, price: 24.99 }, // White, L
  ],
  tags: ["trending", "funny", "meme"]
});
```

## Troubleshooting

### Can't see the button?
- Clear browser cache
- Hard refresh: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)

### Upload fails?
- Check file size (max 50MB)
- Ensure PNG or JPG format
- Check internet connection

### Catalog won't load?
- Verify API token in `.env.local`
- Check Printify service status
- Try refreshing the page
