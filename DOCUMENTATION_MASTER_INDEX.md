## ✍️ Documentation Style Guide

### **Formatting Rules**
- Use Markdown for all docs
- Headers: # for title, ## for sections, ### for subsections
- Code blocks: Triple backticks with language
- Lists: Use - for bullets, numbers for ordered
- Emphasis: **bold** for important, *italic* for notes
- Links: [text](url) format

### **Writing Style**
- Be concise and clear
- Use active voice
- Include examples
- Add diagrams where helpful
- Explain acronyms on first use
- Use consistent terminology

### **Code Examples**
```typescript
// Always include:
// 1. Language in code fence
// 2. Comments explaining purpose
// 3. Complete, runnable examples
// 4. Type annotations (TypeScript)

interface Example {
  property: string; // Clear property names
}
```
