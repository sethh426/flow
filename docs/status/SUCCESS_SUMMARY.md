## 🆘 If Something Goes Wrong

### GitHub Actions Fails?
1. Check workflow logs in GitHub Actions tab
2. Verify all 3 secrets are correct
3. Ensure Firebase token hasn't expired
4. Check `.firebaserc` points to correct project

### Build Fails?
1. Run `cd client && npm install` locally
2. Test build: `npm run build`
3. Fix any errors before pushing

### Deployment Fails?
1. Verify service account has proper roles
2. Check all GCP APIs are enabled
3. Ensure Firebase project exists

### Can't Push to GitHub?
1. Check git remote: `git remote -v`
2. Verify authentication
3. Check branch: `git branch`
