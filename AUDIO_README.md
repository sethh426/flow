# Flow Background Music

To add background music to the early adopter page:

1. Create or obtain an audio file named "let it flow.m4a"
2. Place it in the root directory of your project
3. The page will automatically include audio controls

## Audio Requirements:
- Format: MP4/M4A (AAC encoded)
- Duration: 2-5 minutes (will loop)
- Style: Upbeat, motivational, electronic/ambient
- File size: Under 5MB for web performance

## Alternative:
If you don't have audio, the page will work perfectly without it.
The audio toggle button will simply be hidden if the file is missing.
