# Product Mapper Dashboard

This is a Next.js (React, TypeScript, Tailwind) dashboard for the universal AI-powered product-mapper.

## Features
- Input affiliate URL, selectors (JSON), userId, and match threshold
- Auto-detect selectors (future AI/heuristic placeholder)
- Table/grid to display scraped products and best matches side-by-side
- Approve, edit, or reject matches
- Progress and error feedback
- History of past jobs
- Selector helper: browser-based point-and-click UI (future)

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the development server:
   ```bash
   npm run dev
   ```
3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Backend
- Make sure your product-mapper backend is running and accessible to the dashboard.
