# **App Name**: AffiliateFlow

## Core Features:

- Product Display: Display product details (photo, name, description) scraped from websites like Nordstrom.
- Product Editing: Enable users to edit product information such as the name, description, and affiliate link.
- Approval Setting: Allow users to set whether the product can be approved or rejected
- User Profile: User profile: users should be able to manage user-specific data.

## Style Guidelines:

- Primary color: Sky blue (#87CEEB), evoking the vastness of the internet and the exciting potential of product discovery.
- Background color: Light gray (#F0F0F0) providing a neutral backdrop to emphasize products.
- Accent color: Soft Lavender (#E6E6FA), drawing inspiration from the artistic creativity in marketing content.
- Body and headline font: 'PT Sans', a humanist sans-serif.
- Simple and clear icons for editing, approving, and sharing products.
- Clean and organized layout with a focus on visual presentation of product images.
- Smooth transitions and loading animations to enhance user experience.
