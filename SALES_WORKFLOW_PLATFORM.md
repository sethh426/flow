## 🔧 Key Technical Patterns

### Railway-Oriented Programming
Two-track model for error handling:
- Success track (happy path)
- Failure track (errors, manual review)
- Explicit switching points based on confidence scoring
- Compensating actions for distributed transactions

### Saga Pattern
Distributed transactions with compensation:
- Forward action + compensating transaction for each step
- Central coordinator managing state
- Automatic rollback on failures
- Eventual consistency without distributed locks

### Event-Driven Architecture
- Cloud Functions (540s max, auto-scaling)
- Pub/Sub (at-least-once delivery, 31-day retention)
- Cloud Tasks (500 dispatches/sec, 30-day scheduling)
- Workflows (1-year execution, auto-checkpointing)
