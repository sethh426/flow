## 📋 All ACTION Commands

### **Navigation**
- `navigate(page)` - Go to: overview, campaigns, products, content, trends, analytics, flowchart

### **Campaigns**
- `createCampaign(name, description, budget)`
- `getCampaigns()`
- `updateCampaign(id, updates)`
- `pauseCampaign(id)`
- `activateCampaign(id)`

### **Content**
- `createContent(type, topic, platform)` - Types: post, reel, video, carousel, email
- `generateCaption(topic, tone, length)`
- `findTrendingHashtags(niche, count)`
- `createContentCalendar(duration, frequency)`

### **Publishing**
- `schedulePost(content, date, time, platform)`
- `publishNow(content, platform)`
- `reschedulePost(postId, newDate, newTime)`

### **Analytics**
- `getAnalytics(period)` - today, week, month, quarter, year
- `getTopPerformers(limit, metric)`
- `comparePerformance(period1, period2)`
- `predictRevenue(period)`

### **Products**
- `addProduct(title, description, price, link)`
- `getProducts()`
- `searchProducts(query)`

### **Trends**
- `findTrends(category)` - fashion, beauty, tech, food, lifestyle
- `analyzeTrend(trendId)`
- `createTrendBasedContent(trendId)`

### **Workflows**
- `recommendWorkflow(category)` - marketing, sales, content, automation
- `startWorkflow(workflowId)`

### **Integrations**
- `connectIntegration(service)` - shopify, instagram, tiktok, printify, stripe
- `checkIntegrationHealth()`

### **AI Actions**
- `generateImage(description, style, dimensions)`
- `generateVideo(script, style, duration)`
- `improveContent(contentId, aspect)`
- `abTestContent(contentA, contentB, metric)`

### **Business Intelligence**
- `identifyOpportunities()`
- `detectProblems()`
- `suggestOptimizations()`

## 🆘 Common Issues & Solutions

### **"FlowBot isn't responding"**
- Check GEMINI_API_KEY is configured
- Verify dev server is running
- Check browser console for errors

### **"Content quality seems off"**
- Review brand blueprint settings
- Adjust automation level
- Provide more specific instructions
- Use "improve content" action

### **"Posts failing to publish"**
- Check integration health
- Reconnect social accounts
- Verify API limits not exceeded
- Review FlowBot's error messages

### **"Analytics not showing"**
- Ensure integrations are connected
- Check date range selected
- Verify data sync completed
- Try refreshing the page
